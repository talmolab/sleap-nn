    BalancedSamplerConfig ¶

    Per-file batch composition (crop_pipeline="warp", the bbox_* models and, experimentally, the bottomup, centroid and single_instance models without tiling).

    Every training batch takes a fixed number of samples from each training file (in train_labels_path order), so small datasets are oversampled. With per_sample, each sample instead comes from file g with probability weights[g] (drawn with replacement), which mixes any number of files at any batch size. An epoch is train_steps_per_epoch batches summed over ranks (default: one pass over the training instances). Under DDP each rank draws its own stream (seed + rank) instead of a shard, and the stream position is saved in checkpoints, so a resumed run continues where it stopped.

    Attributes:

    Name Type Description
    counts Optional[List[int]]

    (list of int) Samples per file per batch (sum = per-GPU batch size).
    weights Optional[List[float]]

    (list of float) Relative share per file, rounded to train_data_loader.batch_size. Used when counts is None; equal shares when both are None.
    per_sample bool

    (bool) Draw every sample's file at random with probability weights (normalized; equal when None) instead of fixed per-batch counts. Default: False.
    overlap_weight float

    (float) Experimental (may change or be removed without a deprecation period; no measured benefit in the developers' tests). bbox_* models with per_sample only: within each file, a frame whose labelled boxes overlap (two boxes sharing at least overlap_min of the smaller box's area) is drawn overlap_weight times as often as the file's other frames. Each file's share of the samples is unchanged. 1.0 leaves sampling as it is. Default: 1.0.
    overlap_min float

    (float) Overlap of two labelled boxes, as a share of the smaller box, that makes a frame count for overlap_weight. Default: 0.25.

    (str) Experimental. bbox_* models with per_sample only: read each training frame's relative sampling weight within its file from the labelled frame's metadata under this key (LabeledFrame.metadata[key], a number >= 0; frames without it weigh 1). Each file's share of the samples is unchanged; combines with overlap_weight by multiplying. Not written to training_config.yaml while None. Default: None.

class BalancedSamplerConfig:
    """Per-file batch composition (`crop_pipeline="warp"`, the `bbox_*` models and, experimentally, the `bottomup`, `centroid` and `single_instance` models without tiling).

    Every training batch takes a fixed number of samples from each training file
    (in `train_labels_path` order), so small datasets are oversampled. With
    `per_sample`, each sample instead comes from file `g` with probability
    `weights[g]` (drawn with replacement), which mixes any number of files at any
    batch size. An epoch is
    `train_steps_per_epoch` batches summed over ranks (default: one pass over the
    training instances). Under DDP each rank draws its own stream (seed + rank)
    instead of a shard, and the stream position is saved in checkpoints, so a
    resumed run continues where it stopped.

    Attributes:
        counts: (list of int) Samples per file per batch (sum = per-GPU batch size).
        weights: (list of float) Relative share per file, rounded to
            `train_data_loader.batch_size`. Used when `counts` is `None`; equal
            shares when both are `None`.
        per_sample: (bool) Draw every sample's file at random with probability
            `weights` (normalized; equal when `None`) instead of fixed per-batch
            counts. *Default*: `False`.
        overlap_weight: (float) Experimental (may change or be removed without a
            deprecation period; no measured benefit in the developers' tests).
            `bbox_*` models with `per_sample` only: within each
            file, a frame whose labelled boxes overlap (two boxes sharing at least
            `overlap_min` of the smaller box's area) is drawn `overlap_weight` times
            as often as the file's other frames. Each file's share of the samples
            is unchanged. `1.0` leaves sampling as it is. *Default*: `1.0`.
        overlap_min: (float) Overlap of two labelled boxes, as a share of the
            smaller box, that makes a frame count for `overlap_weight`.
            *Default*: `0.25`.
        frame_weight_key: (str) **Experimental.** `bbox_*` models with
            `per_sample` only: read each training frame's relative sampling weight
            within its file from the labelled frame's metadata under this key
            (`LabeledFrame.metadata[key]`, a number >= 0; frames without it weigh
            `1`). Each file's share of the samples is unchanged; combines with
            `overlap_weight` by multiplying. Not written to `training_config.yaml`
            while `None`. *Default*: `None`.
    """

    weights: Optional[List[float]] = None
    per_sample: bool = False
    overlap_weight: float = field(default=1.0, validator=validators.gt(0))
    overlap_min: float = field(
        default=0.25, validator=[validators.gt(0), validators.le(1)]

    CoordinateLossesConfig ¶

    Coordinate losses through a frozen linear keypoint autoencoder (experimental).

    For centered_instance models only. A soft-argmax (integral regression, Sun et al. 2018) turns each predicted confidence map into differentiable coordinates in crop pixels, and one of two terms goes through a frozen affine-combining autoencoder (Sárándi, Hermans and Leibe 2023): W_enc (L x J) maps J keypoint channels to L latent points and W_dec (J x L) maps them back. Set exactly one of the two weights:

    • consistency: the head predicts the J channels as usual (the confidence-map loss is unchanged) and consistency * |P - W_dec W_enc P|_1 is added, P being the soft-argmax coordinates. The head's part names must be the autoencoder's channel names (any order).
    • decoded: the head predicts the L latent points (its channels become latent_00, latent_01, ...) and the whole loss is decoded * |W_dec Q - Y|_1 over the channels each sample labels, Q being the soft-argmax latent points and Y the labelled coordinates (weighted by the per-node weights). The saved model is a plain centered-instance model that predicts the latent points; decode them with W_dec. No confidence-map loss is computed, so the latent maps' height is arbitrary: predict with a very low peak_threshold (e.g. -1e9). Post-training evaluation is turned off for this term.

    Off unless set; runs without it save nothing new in training_config.yaml.

    Attributes:

    Name Type Description
    autoencoder Optional[str]

    (str) Path to the .npz file with W_enc (L x J), W_dec (J x L), names (the J channel names) and, optionally, latent_partner (the left/right partner index of each latent point, itself for a centre point). Rows of both matrices must sum to 1 (affine combinations), so the terms do not depend on where the crop sits in the frame. Required.
    consistency float

    (float) Weight of the consistency term. Default: 0.0.
    decoded float

    (float) Weight of the decoded-coordinate term. Default: 0.0.
    soft_argmax_beta float

    (float) Inverse temperature of the soft-argmax: the coordinates are the expectation over softmax(beta * map). Over a whole map trained towards Gaussians of height 1 the flat background needs a large value (20); too large a value narrows the peak below a grid cell and rounds the estimate towards the grid. Default: 20.0.
    soft_argmax_window Optional[int]

    (int) Run the soft-argmax only over the grid cells within this many cells of each map's maximum (None: the whole map, as in Sun et al. 2018). A window of about 3 * sigma cells (the head's sigma is in grid cells) with soft_argmax_beta: 10 locates Gaussian peaks to about 0.2 cells even on noisy maps. Default: None.
    data_head Optional[Dict[str, Any]]

    (dict) Filled in by training for the decoded term: the head settings the data loader uses (part_names of the labelled channels and the anchor settings), since the saved head describes the latent points. Leave unset. Default: None.

                "predict the autoencoder's channels, the decoded term its latent "
                "points)."

            raise ValueError(message)

    CosineAnnealingWarmupConfig ¶

    Configuration for Cosine Annealing with Linear Warmup scheduler.

    The learning rate increases linearly during warmup, then decreases following a cosine curve to the minimum value.

    Attributes:

    Name Type Description
    warmup_epochs int

    (int) Number of epochs for linear warmup phase. Default: 5.
    max_epochs Optional[int]

    (int) Total number of training epochs. Will be overridden by trainer's max_epochs if not specified. Default: None.
    warmup_start_lr float

    (float) Learning rate the warmup ramp starts from. The ramp leaves out its start point: epoch e of the warmup trains at (e + 1) / (warmup_epochs + 1) of the way to the base learning rate, so the first epoch does not train at warmup_start_lr. A per-step warmup (warmup_steps) starts there: step s trains at s / warmup_steps of the way. Default: 0.0.
    eta_min float

    (float) Minimum learning rate at end of cosine decay. Default: 0.0.
    warmup_steps Optional[int]

    (int) Warmup length in optimizer steps (iterations). Setting it (0 included) switches the schedule to per-step updates: the learning rate changes every optimizer step instead of every epoch, warmup_epochs is ignored, and the cosine runs over max_steps. None keeps the per-epoch schedule (warmup epoch e trains at (e + 1) / (warmup_epochs + 1) of the way to the base LR). Default: None.
    max_steps Optional[int]

    (int) Total schedule length in optimizer steps when warmup_steps is set. None uses this schedule's max_epochs times the optimizer steps per epoch when that is set, else the run's total optimizer steps (trainer_config.max_epochs, capped by trainer_config.max_steps). Default: None.

    DistillationConfig ¶

    DWPose-style knowledge distillation (Yang et al. 2023, arXiv 2307.15880).

    Experimental: it may change or be removed without a deprecation period, its defaults are untuned, and it showed no measured benefit in the developers' tests.

    Stage 1 (teacher -> student) adds to the supervised loss r(t) * (alpha * L_feat + beta * L_heatmap):

    • L_feat: MSE between the teacher's deepest backbone feature (a plain ViT's last tapped token map, else the bottleneck) and the student's, mapped to the teacher's channels by a trainable 1x1 projector. The projector is dropped from saved checkpoints.
    • L_heatmap: MSE between teacher and student confidence maps over the nodes they share BY NAME (a COCO-17 teacher can teach a larger student skeleton), node-weighted like the supervised loss (see mask_unlabeled_nodes).
    • r(t) = 1 - t / T over the run's optimizer steps (decay; stage 1 only by default).

    Stage 2 (head self-distillation): the student's own trained head becomes the teacher; everything except trainable is frozen (and kept in eval mode when the whole backbone is frozen), trainable is re-initialized, and the new head learns gamma * L_heatmap against the old one (no supervised loss by default, as in DWPose).

    The teacher is frozen, in eval mode, outside the state dict, optimizer and checkpoints, and is replicated on every DDP rank without DDP wrapping.

    Box detectors (bbox_centernet, bbox_ssd, bbox_detr; experimental, stage 1 only): the teacher is a trained box detector of any of the three styles, and L_heatmap is replaced by L_box, the student's own detection loss against the teacher's detections on the same training frame (scores >= teacher_score_threshold; categories matched by name, or one category to one; the teacher must detect every student category) used as targets.     run_name_prefix = legacy_config_outputs.get("run_name_prefix", "")
    run_name_suffix = legacy_config_outputs.get("run_name_suffix", "")
    run_name = (
        run_name_prefix
        if run_name_prefix is not None
        else "" + run_name + run_name_suffix if run_name_prefix is not None else ""
    )
    run_name = None if run_name == "" else run_name

    trainer_cfg_args = {}
    train_dataloader_cfg_args = {}
    val_dataloader_cfg_args = {}
    model_ckpt_cfg_args = {}
    optimizer_cfg_args = {}
    lr_scheduler_cfg_args = {}
    reduce_lr_on_plateau_cfg_args = {}
    early_stopping_cfg_args = {}
    zmq_cfg_args = {}
    online_hard_keypoint_mining_cfg_args = {}

    # train dataloader
    if legacy_config_optimization.get("batch_size", None) is not None:
        train_dataloader_cfg_args["batch_size"] = legacy_config_optimization[
            "batch_size"
        ]

    if legacy_config_optimization.get("online_shuffling", None) is not None:
        train_dataloader_cfg_args["shuffle"] = legacy_config_optimization[
            "online_shuffling"
        ]

    if legacy_config_optimization.get("num_workers", None) is not None:
        train_dataloader_cfg_args["num_workers"] = legacy_config_optimization[
            "num_workers"

            "num_workers"

        legacy_config_outputs.get("checkpointing", {}).get("latest_model", None)

            "latest_model"

                "max_hard_keypoints", None

    # actually enabled the corresponding channel. `subscribe_to_controller` /
    # `publish_updates` are booleans, so a `False` here must leave the port unset
    # (i.e. ZMQ off) rather than being treated as "present".
    if legacy_zmq.get("subscribe_to_controller", False) and legacy_zmq.get(
        "controller_address", None
    ):
        zmq_cfg_args["controller_port"] = int(
            legacy_zmq["controller_address"].split(":")[-1]
        )

    if legacy_zmq.get("publish_updates", False) and legacy_zmq.get(
        "publish_address", None
    ):
        zmq_cfg_args["publish_port"] = int(legacy_zmq["publish_address"].split(":")[-1])

    if legacy_zmq.get("controller_polling_timeout", None) is not None:
        zmq_cfg_args["controller_polling_timeout"] = legacy_zmq[
            "controller_polling_timeout"
        ]

    trainer_cfg_args["zmq"] = ZMQConfig(**zmq_cfg_args)

    return TrainerConfig(**trainer_cfg_args)
